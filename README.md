# 小橙碎无尽冬日脚本 — 小白使用指南

本文档面向零基础用户，介绍如何安装、运行本项目，以及如何修改参数、维护模板图片。

---

## 一、项目能做什么？

本项目通过 **ADB + 屏幕画面识别（模板匹配）** 自动操作《无尽冬日》游戏，提供图形化控制面板，一键开关各类任务。

### 目前已稳定可用的功能


| 功能        | 控制面板名称 | 说明                    | 飞书通知（需开启 `feishu_bot`）                           |
| --------- | ------ | --------------------- | ------------------------------------------------ |
| 抢红包       | 抢红包    | 自动扫描聊天频道中的红包并点击开启     | 抢到红包时推送，如：`[抢红包] 已抢到一个联盟红包！`                     |
| 打熊        | 打熊     | 自动在联盟集结页查找可用队伍并出征打熊   | 任务启停等面板事件（`[任务通知]`），出征本身不单独推送                    |
| 联盟总动员专属刷新 | 专属任务刷新 | 在联盟总动员活动页，按间隔自动刷新专属坑位 | 发现高价值目标任务时推送，如：`[联盟总动员] 坑位1 发现目标任务！模板=拳头，积分=600` |
| 自动集结巨兽    | 集结巨兽   | 检测野外集结人数，自动发起冰原巨兽集结   | 集结成功/失败时推送，如：`[集结巨兽] 集结成功！将在 7 分钟后继续`            |


> 配置好 `config.yaml` 中的 `feishu_bot`（`enabled: true` 并填写密钥）后，上述通知会发到飞书群；任务开启/停止、设备连接等也会以 `[任务通知]` 前缀推送。
>
> 其他功能（如「联盟总动员」导航、「公共任务抢」等）仍在完善中，使用前请自行测试。

## 二、环境准备（必读）

### 2.1 电脑端

- **操作系统**：Windows 10 / 11
- **Python**：3.10 或以上（推荐 3.10）
- **模拟器**：**雷电模拟器（LDPlayer）**（其他模拟器可自行尝试，不保证兼容）

### 2.2 模拟器设置（非常重要）

以下设置直接影响模板能否匹配成功，**必须按此配置**：

1. **分辨率设为 `1920 × 864`（横屏）**
  - 雷电模拟器 → 右侧工具栏 → **设置** → **分辨率**
  - 选择自定义，填入宽 `1920`、高 `864`
  - 分辨率不对会导致所有图标识别失败
2. **开启 ADB 调试**
  - 雷电模拟器 → **设置** → **其他设置**
  - 打开 **ADB 调试**（部分版本叫「本地连接」）
3. **启动模拟器并进入游戏**
  - 打开《无尽冬日》，停留在正常游戏界面
  - 建议游戏内 UI 缩放保持默认，不要随意改 DPI
4. **确认 ADB 能连上**
  - 打开 PowerShell 或 CMD，执行：
  - 正常输出示例：
    ```
    List of devices attached
    emulator-5554   device
    ```
  - 若显示 `unauthorized` 或列表为空，请重启模拟器并重新开启 ADB 调试

### 2.3 安装 Python 依赖

在项目根目录（`wjdr-helper` 文件夹）打开终端，执行：

```powershell
# 1. 创建并激活虚拟环境（推荐，只需做一次）
python -m venv venv
.\venv\Scripts\Activate.ps1

# 2. 安装依赖
pip install scrcpy-client adbutils opencv-python pillow pyyaml lark-oapi rapidocr-onnxruntime ddddocr
```

> 如果项目里已有 `venv` 文件夹，直接激活即可：
>
> ```powershell
> .\venv\Scripts\Activate.ps1
> ```

## 三、修改配置文件

所有参数集中在项目根目录的 `**config.yaml**` 文件中，用记事本或 VS Code 打开即可编辑。

### 3.1 模拟器连接（必改项）

```yaml
emulator:
  device_id: "emulator-5554"   # adb devices 里看到的设备 ID
  max_width: 1920               # 与模拟器分辨率宽度一致
  max_fps: 12                   # 视频流帧率，一般不用改
  adb_path: "D:\\leidian\\LDPlayer9\\adb.exe"  # 改成你电脑上雷电 adb 的实际路径
```

**如何找到 `adb_path`？**

- 雷电默认安装路径常见为 `D:\leidian\LDPlayer9\adb.exe`
- 若安装在其他盘，在雷电安装目录下搜索 `adb.exe` 即可

**如何找到 `device_id`？**

- 运行 `adb devices`，第一列就是设备 ID
- 多开模拟器时可能是 `emulator-5556`、`127.0.0.1:5555` 等，填你正在用的那个

### 3.2 全局识别参数

```yaml
scrcpy_tracker:
  threshold: 0.86    # 模板匹配置信度，越高越严格（识别不到时可适当降低，如 0.80）
  scale: 1.0         # 模板缩放，一般保持 1.0
  method: TM_CCOEFF_NORMED
```

### 3.3 飞书机器人（可选）

```yaml
feishu_bot:
  enabled: true          # 不需要飞书远程控制时改为 false
  app_id: "你的AppID"
  app_secret: "你的AppSecret"
  default_chat_id: "你的群聊ID"
```

> **安全提示**：`app_secret` 是私密密钥，请勿上传到公开仓库或发给他人。

## 四、启动项目

在项目根目录、已激活虚拟环境的终端中执行：

```powershell
python main.py
```

启动后会弹出 **两个窗口**：


| 窗口                  | 作用               |
| ------------------- | ---------------- |
| **控制面板**（主窗口）       | 连接设备、开关任务、查看日志   |
| **Tracker 工具**（子窗口） | 实时预览模拟器画面、调试模板识别 |


### 推荐启动流程

```
1. 先打开雷电模拟器，进入游戏
2. 运行 python main.py
3. 控制面板 →「设备连接」→ 点「刷新」确认设备 ID → 点「▶ 连接设备」
4. 等待状态变为「● 已连接」，Tracker 窗口出现游戏画面
5. 确认调度器已启动（默认自动启动）
6. 在「任务控制」区开启你需要的任务
```

## 五、各功能使用说明

### 5.1 抢红包

1. 控制面板找到 **「抢红包」**，点 **「开启」**
2. 选择模式：
  - **联盟红包**：扫联盟聊天频道
  - **世界红包**：扫世界聊天频道
3. 可调参数（面板内直接改，点「确认」生效）：
  - **扫描间隔**：多久扫一次红包（秒）
  - **点击延迟**：点到红包后，等多久再点开启按钮（秒）

`config.yaml` 中更多参数（一般不用动）：

```yaml
tasks:
  red_packet_task:
    red_packet_threshold: 0.9        # 红包识别阈值
    world_chat_entry_pos: [159, 139]   # 世界聊天入口坐标
    alliance_chat_entry_pos: [435, 142] # 联盟聊天入口坐标
    # ... 其余为固定点击坐标，分辨率变化时才需重测
```

### 5.2 打熊

1. 点 **「打熊」→「开启」**
2. 右侧 **「打熊配置」** 区域：
  - 勾选各队伍对应的模板（如「阳光队伍」）
  - 模板图片需提前放到 `assets/templates/` 目录
3. 模式可选 **打熊** 或 **打怪**
4. 队伍出征后有冷却时间，面板提供 **「打熊清冷却」** 按钮手动清除

`config.yaml` 关键参数：

```yaml
tasks:
  bear_attack_task:
    teams:
      1: ["阳光队伍"]    # 队伍1 对应的模板名（与图片文件名一致，不含 .png）
      2: []
      3: []
      4: []
    team_cooldown_secs: 324   # 队伍冷却秒数（约 5.4 分钟）
    rally_template: "熊集结页"  # 判断是否在集结页的模板名
```

### 5.3 联盟总动员专属刷新

1. 确保游戏已能进入 **联盟总动员活动页**（可先手动导航一次确认）
2. 点 **「专属任务刷新」→「开启」**
3. 可在面板设置两个坑位的刷新间隔：**2 分钟** 或 **5 分钟**

工作原理简述：

- 自动滑动到专属任务区域顶部
- 按间隔检查两个坑位，识别到高价值目标（如「拳头」）且积分超过阈值时发飞书提醒
- 否则自动点击「刷新任务」→「确认刷新任务」

`config.yaml` 关键参数：

```yaml
tasks:
  alliance_monitor_task:
    valuable_templates:    # 高价值目标模板
      - "拳头"
    score_threshold: 500   # OCR 积分超过此值才提醒
    slot_refresh_secs: [300, 300]  # 坑位1、坑位2 刷新间隔（秒）
```

> **注意**：「专属任务刷新」与「公共任务抢」默认互斥，不能同时开（除非勾选「专属+公共同时开」）。

### 5.4 自动集结巨兽

1. 点 **「集结巨兽」→「开启」**
2. 脚本会自动导航到野外，OCR 识别当前集结人数
3. 人数 ≤ 阈值时自动执行：查找 → 冰原巨兽 → 搜索 → 集结 → 发起集结 → 编队 → 出征

`config.yaml` 关键参数：

```yaml
tasks:
  giant_beast_rally_task:
    check_interval_secs: 2.0      # 检测间隔（秒）
    rally_cooldown_secs: 450.0    # 两次集结之间的冷却（秒）
    ocr_count_threshold: 15       # 人数 ≤ 此值时发起集结
    ocr_region: [805, 598, 872, 632]  # OCR 裁剪区域，分辨率变化需重测
```

## 六、模板图片维护（重要）

本项目靠 **模板匹配** 识别游戏界面上的按钮和图标。模板图片存放在：

```
assets/templates/
```

文件名（不含 `.png` 后缀）即为模板名称，代码和配置里引用的名字必须与文件名一致。

### 6.1 截取模板的正确方法

> **核心原则：在模拟器里截屏，查看时缩放 100%，再截取模板区域。**

**推荐步骤（雷电模拟器）：**

1. 在游戏中定位到需要识别的按钮/图标
2. 使用模拟器自带截图（或 Tracker 窗口的「截帧裁图」）
3. 用图片查看器打开截图，**缩放比例设为 100%**（不要放大或缩小）
4. 只截取目标图标本身，尽量少带背景
5. 将截好的图片 **直接粘贴** 到 Tracker 工具中

**在 Tracker 中粘贴模板：**

1. 复制截图到剪贴板（`Ctrl+C`）
2. 切换到 Tracker 窗口
3. 按 `**Ctrl+V`**，或点击 **「粘贴 Ctrl+V」** 按钮
4. 输入模板名称（如 `红包`、`熊集结页`），确认保存
5. 模板会自动保存到 `assets/templates/` 目录

### 6.2 验证模板是否可用

1. Tracker 窗口连接设备后，左侧模板列表应能看到刚添加的模板
2. 点击 **「开始跟踪」**，游戏画面上会出现绿色框标注匹配位置
3. 若框位置偏移或找不到：
  - 降低 **置信阈值**（如从 0.86 改为 0.80）试试
  - 重新按 100% 比例截取更干净的模板
  - 确认模拟器分辨率仍是 **1920×864**

### 6.3 各任务常用模板参考


| 任务   | 常用模板名                              |
| ---- | ---------------------------------- |
| 抢红包  | `世界地图`、`地球按钮`、`世界聊天`、`红包`、`开启按钮`   |
| 打熊   | `熊集结页`、`联盟战争`、`阳光队伍`（自定义队伍名）等      |
| 专属刷新 | `拳头`、`刷新任务`、`确认刷新任务`、`坑位1`、`坑位2` 等 |
| 集结巨兽 | `城镇大门`、`查找按钮` 等（点击坐标多在 config 里配置） |
| 通用导航 | `关闭按钮`、`返回按钮`、`无尽冬日`（启动游戏用）        |


完整列表见 `assets/templates/` 目录下的现有文件。

## 八、常见问题

### Q1：连接设备失败 / 画面黑屏

- 确认模拟器已启动且 ADB 调试已开启
- 检查 `config.yaml` 中 `adb_path` 和 `device_id` 是否正确
- 在控制面板点「刷新」重新获取设备列表
- 尝试重启模拟器和脚本

### Q2：模板全部识别不到

- **首先检查分辨率是否为 1920×864**
- 检查 `max_width` 是否设为 `1920`
- 在 Tracker 中降低 `threshold` 试试
- 按本文第六节重新截取模板（100% 比例）

### Q3：点击位置偏移

- 分辨率或游戏 UI 缩放变了，需要重新测量 `config.yaml` 中的坐标
- 可借助 Tracker 窗口，鼠标悬停在画面上查看坐标

### Q4：抢红包点了但没开到

- 适当增大 `click_delay_secs`（点击延迟）
- 检查 `开启按钮` 模板是否清晰
- 确认当前聊天频道模式（联盟/世界）选对

### Q5：打熊找不到队伍

- 确认 `assets/templates/` 中有对应队伍模板（如 `阳光队伍.png`）
- 在右侧打熊配置区勾选该模板
- 检查是否处于联盟集结页（`熊集结页` 模板能匹配）

### Q6：专属刷新 / 集结巨兽 OCR 不准

- 确认安装了 `ddddocr` 或 `rapidocr-onnxruntime`
- 检查 `ocr_region` 坐标是否覆盖完整数字区域
- 分辨率变化后需重新标定 OCR 区域

### Q7：提示缺少某个 Python 包

按提示安装，例如：

```powershell
pip install scrcpy-client
pip install pyyaml
pip install rapidocr-onnxruntime
```
