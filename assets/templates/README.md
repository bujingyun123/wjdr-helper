# 模板图片目录

此目录存放 OpenCV 模板匹配所需的截图片段。

## 抢红包任务所需模板

| 文件名          | 用途说明                              | 截取建议                             |
|-----------------|---------------------------------------|--------------------------------------|
| `世界地图.png`  | 检测是否处于主界面（世界地图视角）    | 截取世界地图左上角的特征性图标或文字 |
| `地球按钮.png`  | 点击打开聊天窗口的地球/聊天图标      | 截取主界面底部聊天入口图标           |
| `世界聊天.png`  | 检测是否已进入世界聊天频道页面        | 截取世界聊天页顶部标题或标识区域     |
| `红包.png`      | 识别聊天列表中的红包消息图案          | 截取聊天中红包消息的特征图案         |
| `开启按钮.png`  | 点击开启红包的「开启」按钮            | 截取红包弹窗中的开启按钮             |

## 如何截取模板图片

**方法一：通过 Tracker 工具截图**
1. 运行 `python main.py` 或独立运行 `python tools/scrcpy_tracker.py`
2. 连接设备，待画面出现后点击「截帧裁图」
3. 在游戏画面上拖拽框选目标区域，输入对应名称（如 `world_map`）保存

**方法二：通过 Tracker 工具粘贴**
1. 在其他截图工具中截取目标图案，复制到剪贴板
2. 在 Tracker 工具中按 `Ctrl+V` 粘贴并命名

**注意事项**
- 模板图片应尽量清晰，避免包含过多背景
- 建议在游戏分辨率稳定时截取
- 如果识别率低，可在 Tracker 工具中调整「置信阈值」和「模板缩放」
- 截取后的模板图片会保存到 `tools/pasted_templates/`，可手动移动到此目录
